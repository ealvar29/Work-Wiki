Internal tools built by the Jaxon Digital team to accelerate development and client upgrade workflows.

## Upgrade Tools

- [[upgrade-assistant-mcp|Optimizely Upgrade Assistant MCP]] — assess → plan → verify workflow for CMS 12 → CMS 13 upgrades; outputs Jira/Azure DevOps exports and feeds directly into the AI-assisted upgrade workflow
- [[client-claude-md-generator|Client CLAUDE.md Generator]] — generates a self-contained `CLAUDE.md` for any client upgrade project, pulling inline content from the wiki so the agent starts with full upgrade context

## Client Audit Tools

- [[ai-readability-mcp|AI Readability MCP]] — audits any website for AI crawler readability across 8 dimensions (robots.txt, structured data, llms.txt, rendering, and more); produces a graded report, client-facing deliverable, and ready-to-deploy llms.txt
